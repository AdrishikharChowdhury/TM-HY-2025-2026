{\sffamily\bfseries\color{IEEEblue!75!black}DID YOU KNOW?}\quad
IPv6 provides $2^{128}$ addresses---approximately $3.4\times10^{38}$. MQTT is lightweight, but it does not encrypt messages by itself; secure deployments normally use TLS. CoAP commonly uses UDP to reduce overhead, while edge computing processes urgent data near devices to lower latency and bandwidth use.
